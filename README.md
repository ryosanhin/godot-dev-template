# godot-dev-template

My template for godot projects.

## 使い方

1. `project.godot` の`config/name` をプロジェクト名に変更する。
2. `AGENTS.md` の`<>`で囲まれた部分をプロジェクト毎にいい感じに書き換える。
3. テストを追加したら、`docs/examples/` 以下の見本の`.yml` ファイルを`.github/workflows/` に置く。
4. 見本の`some test` を実際のテスト名に書き換え、`tests/some_test.gd` を実際のテストパスに書き換える。
